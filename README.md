# 欧洲出差报销助手（Web App）

一个纯前端应用，用于解决工程师出差报销时反复查政策、遗漏规则、回国后对账困难的问题。

## 解决的痛点

- **政策分散、每次都要登录内网查询**：将城市政策配置内置在页面中，打开即用。
- **出差中临时变更多**：支持录入“换酒店附加费、机票改签费、额外交通费”，实时更新预算。
- **报销容易踩红线**：自动提示酒店超标审批等关键注意事项。
- **回国后提交材料麻烦**：支持导出报销说明文本，减少手工整理。

## 快速使用

直接在浏览器打开 `index.html`。

## 可扩展方向

- 接公司 SSO + 政策 API，同步最新报销制度。
- 增加多币种和汇率快照。
- 增加票据上传与 OCR 自动分类。
- 导出为公司标准报销模板（Excel/PDF）。
