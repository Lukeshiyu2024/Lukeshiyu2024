# 欧洲出差报销助手 Pro（Web App）

一个纯前端 Web App，解决工程师欧洲出差报销常见问题：政策查找繁琐、费用变更难记录、票据容易遗漏。

## 本次优化

- **界面升级**：采用更现代的卡片+渐变风格，信息分组更清晰。
- **可上传图片**：支持多张票据图片本地预览，便于出差中快速归档核对。
- **流程闭环**：从预算估算、变更录入到导出说明，一页完成。

## 快速使用

直接在浏览器打开 `index.html`。

## 后续可扩展

- 对接公司登录与政策接口（自动同步制度）。
- 上传票据后接 OCR 自动提取金额与日期。
- 导出公司标准报销模板（Excel/PDF）。
